How wallet privacy works

A plain-language summary of what FRTC’s Tor connection does—and its limits.

Wallet traffic: When you open the wallet, FRTC starts its included Tor connection. Bitcoin wallet network traffic is sent through Tor, and FRTC stops the Tor process it started when you close the wallet.

Receive QR: The wallet QR encodes the current Bitcoin address as a bitcoin: URI. Always check the address and network on the sending wallet before paying.

What this helps with: It helps keep your home IP address from being directly exposed to Bitcoin peers. Your internet provider may still see that you are connecting to Tor.

What it does not cover: Tor is used for wallet networking only. Sign-in and chat connect to Firebase separately, so Firebase may associate those requests with your signed-in account. Bitcoin transactions and addresses are public, and Tor does not make them anonymous.

Current status: The wallet and its privacy setup are experimental and have not been independently audited or validated with real Bitcoin mainnet funds. Do not deposit or send real BTC.

How to download and install

Your download appears in the browser’s Downloads list or in your Downloads folder.

Windows installer
  1. Select Download Windows installer above.
  2. When it finishes, open FRTC_Messenger_windows_installer.msi.
  3. Follow the installer prompts, then open FRTC Messenger from the Start menu. Tor is included and runs only while the wallet is open.
Debian / Ubuntu installer
  1. Select the Debian / Ubuntu .deb download above.
  2. Open a terminal in your Downloads folder.
  3. Run sudo apt install ./FRTC_Messenger_linux.deb, then launch FRTC Messenger from the applications menu. Tor is included; no separate Tor installation is needed.
Fedora installer
  1. Select Fedora (.rpm) above.
  2. Open a terminal in your Downloads folder.
  3. Run sudo dnf install ./FRTC_Messenger_linux.rpm. Fedora will install required packages; then launch FRTC Messenger from the applications menu. Tor is included.
Android APK preview
  1. Download the Android APK above on your phone.
  2. Open the downloaded APK. If Android asks, allow your browser or file manager to install apps from this source.
  3. Review the Android preview notes on GitHub. This build is debug-signed for direct installation, requires verified email, and contains chat only.
Portable Linux version (Fedora, Arch, and others)
  1. Download and extract FRTC_Messenger_linux.zip.
  2. Open a terminal in the extracted folder—the one containing bin, ico, and lib.
  3. Install the desktop libraries, then make the launcher executable and run it. Tor is already included in the ZIP:

Debian / Ubuntu

sudo apt update
sudo apt install libxrender1 libxtst6 libxi6 libfontconfig1 fonts-dejavu-core

Fedora

sudo dnf install libXrender libXtst libXi fontconfig dejavu-sans-fonts

Arch Linux

sudo pacman -Syu --needed libxrender libxtst libxi fontconfig ttf-dejavu
chmod +x "./bin/FRTC Messenger"
./bin/FRTC\ Messenger

Run the last two commands in the extracted app folder. On WSL, use WSLg or an X server to display the app window.

Windows portable ZIP and legacy editions

Legacy Windows edition (32-bit, Windows 7 SP1 and newer): chat only. This edition does not include the Bitcoin wallet or Tor, so there is no Tor setup or Tor service to start for it. For the installer, download and open the legacy MSI, then follow its prompts and launch FRTC Messenger from the Start menu. For the portable ZIP, extract all files to a folder you can access, then open FRTC_Messenger_Legacy.exe from that extracted folder. Keep the other extracted files beside the EXE.

If you use Windows 7 SP1 and sign-in cannot connect, the optional network patch below adds TLS support within the FRTC folder. It is experimental and has not been independently verified on every Windows 7 setup. It backs up replaced app files and does not change Windows system files. Close FRTC before running the patch, then select the existing FRTC folder and read the confirmation. If sign-in still fails, use the full HTTP status and server message shown by the app. Keep the generated .before-frtc-patch-... backups so you can restore the original files. Do not copy Windows 11 DLLs into Windows 7.

Download Windows 7 network patch ↓
  1. Extract the full patch ZIP.
  2. Close FRTC Messenger.
  3. Run FRTC_Win7_TLS_Patch.exe. If FRTC is in Program Files, run it as administrator.
  4. Select the existing FRTC installation folder and read the confirmation before applying.
Already installed? Update, repair, or remove FRTC

Windows: Run a newer MSI to upgrade the matching edition. To repair or remove an installed MSI version, open Settings → Apps → Installed apps, select the matching FRTC Messenger edition, then choose Modify. Reopening the same MSI also opens its maintenance options.

Debian / Ubuntu

# Update using the newly downloaded package
sudo apt install ./FRTC_Messenger_linux.deb
# Repair / reinstall the current package
sudo apt install --reinstall ./FRTC_Messenger_linux.deb
# Remove the app
sudo apt remove frtc-messenger

Fedora

# Update using the newly downloaded package
sudo dnf install ./FRTC_Messenger_linux.rpm
# Repair / reinstall the current package
sudo dnf reinstall frtc-messenger
# Remove the app
sudo dnf remove frtc-messenger

APT and DNF show their normal confirmation before applying package changes. Linux portable ZIPs are managed by you: replace the extracted app folder to update, or delete that folder to remove it.
