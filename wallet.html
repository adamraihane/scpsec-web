WALLET ONLY

Manage a Bitcoin wallet in a separate app.

This edition contains the FRTC wallet interface and its required runtime. It does not include Messenger chat or Firebase sign-in. Windows and Linux packages bundle Tor; the Android preview includes Guardian Project's Tor service. Each app starts Tor when the wallet opens and stops it when the wallet closes.

Choose your operating system.

The wallet includes Bitcoin mainnet receive and send flows. Transactions are broadcast to the public Bitcoin network. These packages contain the apps and required runtimes, not project source files. Android is an experimental send-and-receive preview. View Wallet releases on GitHub ↗

Experimental wallet — try it only at your own risk: Project testing reports that recovery phrase restore, password changes, and phone-to-phone transfers work. Receive and send features are implemented for Bitcoin Mainnet. These checks are not an independent security audit or independent confirmation of a real-funds Mainnet transaction. If you choose to try it, start only with a tiny amount you can afford to lose and verify the address and transaction independently. Do not rely on it for safekeeping or send funds you cannot afford to lose. Tor can help hide your direct IP from Bitcoin peers, but it does not anonymize public transactions or provide complete anonymity.

Install the Linux package

Download the matching package first, then run its install command from the Downloads folder.

Debian / Ubuntu
cd ~/Downloads
sudo apt install ./FRTC_Wallet_linux.deb

Open FRTC Wallet from the applications menu.

Fedora
cd ~/Downloads
sudo dnf install ./FRTC_Wallet_linux.rpm

Open FRTC Wallet from the applications menu.

Portable Linux ZIP
  1. Extract the ZIP archive.
  2. Open a terminal in the extracted wallet folder.
  3. Run chmod +x "./bin/FRTC Wallet", then ./bin/FRTC\ Wallet.
